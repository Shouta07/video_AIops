## 1. Shimonとは何者か

### 本質
```
「変身が好き」
自分が変わるのも、人を変えるのも好き。
完成形じゃなくて、0→100にする過程そのものが好き。
```

### 原体験
- 中学時代、癖毛にアイロンを当てたら周りの目が180度変わった
- センター分けにした時、眉毛の薄さが気になり親のペンシルを借りたら高評価
- 同期のメガネ選びを提案して購入させた
- モンハンでも変形武器（スラアク）が好き

### ポジショニング
```
メンズメイクの「登竜門」
= 始めたい人が最初に見るアカウント
= ファッションにおけるげんじさんのような存在

差別化: プロじゃない。始めたばかりの社会人。
だから「何から？」に本気で答えられる。
```

### プロフィール
```
ユーザー名: @shimon_brushup
名前: shimon
自己紹介: 日常の変身が好きな社会人
```

## 4. 役割分担

### 原則
```
Shimon = 主体。全工程を自分でやる。
しょうた = 黒子。仕組みを作り、裏でチューニングする。
```

### Shimonの担当
| 工程 | やること | 所要時間 |
|------|---------|---------|
| 企画 | ops.pyで台本テーマを選ぶ or 自分で決める | 5分 |
| 台本 | 生成された台本を確認 | 3分 |
| 撮影 | 台本を見ながら撮影 | 30分 |
| 編集 | 素材をinput/に入れてクイック実行 | 5分 |
| 投稿 | 生成されたキャプション・タグをコピペして予約投稿 | 5分 |

**合計: 1本あたり約50分。週3本で2.5時間。**

### しょうたの担当
| 工程 | やること |
|------|---------|
| 初回 | ShimonのPCにシステムをセットアップ |
| 週次 | 数字を確認。伸びた型をテンプレートに追加 |
| 月次 | 戦略の振り返り。次月の方針をShimonと擦り合わせ |
| 随時 | バズ動画の型を分析・追加。仕組みの改善 |

### 介入のライン
```
○ やる:
  - 台本の選択肢を用意する
  - 「今週の素材いつ撮る？」のリマインド
  - 数字の共有（「この動画こうだったよ」）
  - テンプレート・ハッシュタグの更新

× やらない:
  - 投稿の最終判断（Shimonが決める）
  - アカウントにログインして投稿
  - Shimonの言葉を書き換える
  - Shimonのペースを否定する
```

## 5. 信頼関係の設計

### 原則
```
しょうたの仕事 = Shimonが気持ちよく続けられる環境を作ること
数字を伸ばすのはその結果。
```

### 3つのルール

**① 役割と成果を可視化する**
```
先に決めておくこと:
- 誰が何を担当するか（このドキュメント）
- 収益化した場合の分配（ざっくりでいい）
- どちらかが抜けたい時のルール

後から決めると「交渉」→ 関係が壊れる
先に決めると「約束」→ 関係が守られる
```

**② Shimonの成長を実感させる**
```
徐々に渡していく。最初から全部渡さない。
でも最終的には全部Shimonができる状態にする。

Week 1:  しょうたが台本作って見せる → Shimonは撮るだけ
Week 3:  Shimonが台本のテーマを自分で決める
Week 6:  Shimonが投稿文を自分で書いてみる
Week 10: Shimonがバズ動画のURLを自分で見つけてくる
Month 6: Shimonが1人で全部回せる状態

しょうたの成功 = Shimonが自走できるようになること
```

**③ 数字で会話する（感情ではなく）**
```
× 「最近投稿少なくない？」        → 責めてる
○ 「今週の再生数こうだったよ」     → 事実

× 「もっとこうした方がいいよ」     → 指示
○ 「この動画の保存率高いね、なぜだと思う？」 → 一緒に考える
```

### しょうたがやってはいけないこと
```
1. Shimonより詳しくなりすぎない
   あくまでShimonの感性を活かす裏方

2. 成果を自分のものにしない
   表に出るのは常にShimon

3. Shimonのペースを否定しない
   本業が忙しい時は待つ。「もっとやれるだろ」は禁句
   ただし約束した期日は守らせる（対等な関係の維持）
```

### 定期確認
```
月1回:「どう？楽しい？」を聞く
「しんどい」→ 仕組みを見直す。Shimonを責めない
惰性で続けるのが一番危険
```

## 6. ロードマップ

### Phase 1: 0→1,000人（4〜6月 / 3ヶ月）

**目標: 投稿の習慣化 + 型の発見**

| 週 | やること |
|----|---------|
| Week 1 | PCセットアップ。過去動画を整理。最初の3本の台本作成 |
| Week 2 | 最初の3本を投稿。数字を確認 |
| Week 3-4 | 週3投稿を継続。伸びた動画の型を分析 |
| Week 5-8 | 伸びた型を量産。バズ動画の型も取り入れ開始 |
| Week 9-12 | 月1撮影会のリズムを確立 |

**KPI:**
- 投稿数: 36本以上
- 平均再生数: 500以上
- フォロワー: 1,000人

### Phase 2: 1,000→5,000人（7〜9月 / 3ヶ月）

**目標: 当たりパターンの量産**

| 施策 | 内容 |
|------|------|
| 型の量産 | Phase 1で見つけた伸びるパターンを繰り返す |
| 巻き込み系 | 「友達をメイクしてみた」「フォロワーの悩み解決」 |
| シリーズ化 | 「メイク○ヶ月目の変化」で定期的にバズを狙う |
| コメント活用 | コメント返し動画でエンゲージメントUP |

**KPI:**
- 投稿数: 累計72本以上
- 平均再生数: 2,000以上
- フォロワー: 5,000人
- 1万再生超え動画: 3本以上

### Phase 3: 5,000→10,000人（10〜12月 / 3ヶ月）

**目標: 加速 + 収益化準備**

| 施策 | 内容 |
|------|------|
| コラボ | 同規模のクリエイターとコラボ投稿 |
| トレンド | 季節トレンド（夏メイク→秋冬メイク）に乗る |
| 権威性 | 「メイク始めて○ヶ月の変化まとめ」で信頼構築 |
| 収益化 | アフィリエイト・PR案件の準備 |

**KPI:**
- フォロワー: 10,000人
- 平均再生数: 5,000以上
- 1万再生超え動画: 月2本以上

## 7. 週間オペレーション

### Shimonの1週間
```
日曜: ops.pyで台本確認 → 撮影（朝の支度ついでに30分）
月曜: 素材をinput/に入れてクイック実行 → 動画1本目を予約投稿
水曜: 動画2本目を予約投稿（月曜に生成済み）
金曜: 動画3本目を予約投稿（月曜に生成済み）+ 週次数字を確認
```

### しょうたの1週間
```
月曜: Shimonから素材が来たか確認（来てなければ「日曜のやつ来た？」）
水曜: 投稿の数字をチェック
金曜: 週次レポートをまとめてShimonに共有
日曜: 来週の台本案を準備（Shimonが選ぶ用）
```
