## 2. Shimonの強み

### 原体験

```
中学の時、癖毛にアイロンを当てたら周りの目が180度変わった。
→ 0の状態を100にする「変身」にハマった。
```

- 親のペンシルで眉毛を描いたら高評価された
- 同期の顔の特徴からメガネのフレームを提案→購入させた
- 造形美より「変化度」に惹かれる

### 他にない強み

```
「プロじゃない」こと。

プロの発信 → 「すごいけど自分には無理」
Shimonの発信 → 「この人にできるなら俺にもできそう」
```

### ポジショニング

```
メンズメイクの「登竜門」
＝ 始めたい人が最初に見るアカウント
＝ ファッションにおける「げんじ」的な存在

小田切ヒロ → 女性向け・高級品・プロ感
Shimon    → 男性向け・手が届く・同じ目線
```

## 4. コンテンツ戦略

### 3本柱

| 柱 | 内容 | 頻度 | なぜ伸びるか |
|----|------|------|------------|
| ビフォアフ | 変身系 | 週1 | 変化量がTikTokで一番伸びる |
| ハウツー | やり方を教える | 週1 | 保存率が高い→アルゴに有利 |
| GRWM/日常 | 朝の支度 | 週1 | 親近感→フォロー転換率が高い |

### ステップアップ計画

```
Month 1-3:   眉毛だけ
Month 4-6:   眉毛 + BBクリーム
Month 7-9:   + アイブロウマスカラ + リップ
Month 10-12: トータルメイク + ヘア + ファッション
```

**効果:**
- フォロワーが「次は何追加するんだろう」で追いかける
- 初心者が「自分もMonth1から始めよう」で真似する
- 毎月ビフォアフが生まれるので素材が尽きない

### 投稿の型

```
冒頭2秒: フック（「眉毛描くだけでこんな変わる」）
3〜20秒: 本編（過程を見せる）
20〜27秒: 結果（ビフォアフ / 完成）
27〜30秒: CTA（「フォローして一緒にやろう」）
```

### ハッシュタグ戦略

```
固定タグ（毎回）:
  #メンズメイク #メンズ美容 #自分磨き #垢抜け

投稿ごとに追加（AIが自動生成）:
  テーマに合わせたニッチタグ 10〜15個
  大（100万+）: 中（10万+）: 小（1万+）= 3:4:3
```

## 5. 運用体制

### 原則

```
Shimon = 主体。全工程を自分でやる。
しょうた = 黒子。仕組みを作り、裏でチューニングする。
```

### Shimonの工程と所要時間

| 工程 | やること | 時間 |
|------|---------|------|
| 企画 | メニューからテーマを選ぶ or 自分で決める | 5分 |
| 台本 | 自動生成された台本を確認 | 3分 |
| 撮影 | 台本を見ながら撮影 | 30分 |
| 編集 | 素材をフォルダに入れてボタンを押す | 5分 |
| 投稿 | キャプション・タグをコピペして予約投稿 | 5分 |
| **合計** | **1本あたり** | **約50分** |

```
週3本 × 50分 = 週2.5時間
日曜にまとめて撮れば撮影は1回で済む
```

### しょうたの役割

| 頻度 | やること |
|------|---------|
| 初回 | ShimonのPCにシステムをセットアップ |
| 週次 | 数字を確認。伸びた動画を分析 |
| 月次 | 戦略の振り返り。次月の方針を擦り合わせ |
| 随時 | バズ動画の型を追加。仕組みの改善 |

### 週間スケジュール

```
日曜: 台本確認 → 撮影（朝の支度ついでに）
月曜: 素材をフォルダに入れてボタン押す → 投稿1本目を予約
水曜: 投稿2本目を予約
金曜: 投稿3本目を予約 + 数字を確認
```

## 6. 仕組み（ツール）

### Shimonがやること

```
デスクトップのショートカットをダブルクリック
  ↓
メニューが出る → 番号を選ぶだけ
```

```
╔════════════════════════════════════════════╗
║        Video AIops                         ║
╠════════════════════════════════════════════╣
║  1) クイック実行（素材→動画→キャプション）  ║
║  2) 台本を作成（テーマ→台本）              ║
║  3) バズ動画の型（URL→構成コピー）          ║
║  4) 投稿プラン（確認・修正）                ║
║  5) 撮影指示書                             ║
╚════════════════════════════════════════════╝
```

### 何が自動化されるか

| 工程 | 手動でやると | ツール使うと |
|------|------------|------------|
| 台本作成 | 30分〜1時間 | 1分（テーマ入力だけ） |
| テロップ作成 | 15〜30分 | 0分（音声から自動生成） |
| 動画編集 | 30分〜1時間 | 3分（素材入れてボタン） |
| キャプション | 10〜15分 | 0分（自動生成） |
| ハッシュタグ | 10分 | 0分（自動生成） |
| **合計** | **1.5〜3時間** | **5分** |

### バズ動画の型コピー

```
伸びてるTikTok動画のURLを入れる
  ↓
AIが構成を抽象化（「冒頭2秒でフック→過程→ビフォアフ→CTA」）
  ↓
テンプレートとして保存
  ↓
自分の素材をこの型に当てはめて投稿を自動生成

→ 0から考えなくていい。バズの型をコピーするだけ。
```

## 7. ロードマップ

### Phase 1: 0→1,000人（4月〜6月）

**テーマ: 習慣化 + 型の発見**

```
Week 1:  セットアップ。過去動画を整理。最初の3本を投稿
Week 2-4: 週3投稿を継続。伸びた動画を分析
Week 5-8: 伸びた型を量産
Week 9-12: 月1撮影会のリズムを確立
```

**KPI:**
- 投稿: 36本以上
- 平均再生: 500+
- フォロワー: 1,000人

### Phase 2: 1,000→5,000人（7月〜9月）

**テーマ: 当たりパターンの量産**

```
- Phase 1で見つけた伸びる型を繰り返す
- 「友達をメイクしてみた」等の巻き込み系
- 「メイク○ヶ月目の変化」シリーズ
- コメント返し動画でエンゲージメントUP
```

**KPI:**
- 平均再生: 2,000+
- フォロワー: 5,000人
- 1万再生超え: 3本以上

### Phase 3: 5,000→10,000人（10月〜12月）

**テーマ: 加速 + 収益化準備**

```
- 同規模クリエイターとコラボ

```

**KPI:**
- 平均再生: 5,000+

## 8. 約束ごと

### 互いに守ること

```
1. 決めた投稿頻度（週3本）は守る
   → できない週は事前に共有する

2. 数字は毎週共有する
   → 感情ではなく事実で会話する

3. 月1回「どう？楽しい？」を確認する
   → しんどければ仕組みを見直す。人を責めない

4. 収益化の分配は事前に決めておく
   → 後から決めると揉める。先に決めると約束になる

5. 辞めたい時は言う
   → 惰性で続けるのが一番もったいない
```

### Shimonへ

```
撮るのはShimon。投稿するのもShimon。
全部自分でやってる。

ただし「何を撮ろう」「どう編集しよう」「何書こう」で
悩む時間はゼロにした。

やることは3つだけ:
  1. 台本を見て撮る
  2. フォルダに入れてボタンを押す
  3. コピペして投稿する

それだけ続ければ、年末には10,000人いる。
```

### しょうたへ（自分用メモ）

```
Shimonが「自分のアカウント」だと感じ続けることが全て。

成果を自分のものにしない。
Shimonのペースを否定しない。
でも約束した期日は守らせる。

最終ゴール: Shimonがこの仕組みなしでも自走できる状態。
この仕組みが他のクライアントにも展開できる状態。
```
